랜딩페이지를 완성하고 단골 손님 단톡방에 주소를 보냈는데, 미리보기에 **사진이 없거나**, 제작 템플릿 이름이 제목으로 뜨거나, 예전 문구가 그대로 나온 적 있으신가요?

작은 가게에서는 홈페이지 주소가 검색보다 **카카오톡 대화방**으로 더 많이 퍼집니다. 손님이 받는 첫인상은 페이지가 아니라 채팅방에 뜨는 작은 미리보기 카드예요. 이 카드는 페이지 안에 넣어 두는 **OG 태그**로 정해집니다.

이 글은 **OG 태그가 무엇인지**, **썸네일과 문구를 어떻게 정할지**, **바꿨는데 반영이 안 될 때** 순서로 정리했습니다.

> 아래 태그 이름과 카카오 도구 메뉴는 2026년 11월 12일에 Open Graph 프로토콜 공식 사이트와 카카오디벨로퍼스 문서에서 확인했습니다. 도구 화면은 바뀔 수 있으니 실제 메뉴 이름은 각 사이트에서 다시 확인하세요.

## OG 태그가 뭔가요?

OG는 **Open Graph(오픈 그래프)**의 줄임말입니다. 링크를 공유했을 때 어떤 제목, 설명, 사진을 보여 줄지 페이지가 직접 알려 주는 약속이에요. 카카오톡, 페이스북, 인스타그램 DM, 문자 앱 등 많은 서비스가 이 정보를 읽어 미리보기를 만듭니다.

Open Graph 공식 사이트는 기본 속성으로 `og:title`, `og:type`, `og:image`, `og:url` 네 가지를 안내하고, `og:description`, `og:site_name` 같은 항목은 선택으로 둡니다. ([The Open Graph protocol](https://ogp.me/))

| 태그 | 미리보기에서 보이는 곳 | 작은 가게에서 쓰는 예 |
|---|---|---|
| og:title | 카드의 굵은 제목 | ○○필라테스 체험 수업 신청 |
| og:description | 제목 아래 한두 줄 | 강남역 5분, 1:1 맞춤 수업 |
| og:image | 카드의 사진 | 매장 대표 사진 |
| og:url | 이 페이지의 대표 주소 | https://내도메인.com/ |
| og:type | 보이지 않음 (페이지 종류) | website |

## 이렇게 넣으면 됩니다

페이지의 `<head>` 안에 아래처럼 넣습니다. 홈페이지 빌더를 쓴다면 보통 "SEO 설정", "공유 설정" 같은 메뉴에서 같은 내용을 칸에 채우는 방식이에요.

```html
<meta property="og:type" content="website">
<meta property="og:title" content="○○필라테스 | 첫 체험 수업 신청">
<meta property="og:description" content="강남역 5분, 1:1 맞춤 필라테스. 체험 수업 신청을 받고 있습니다.">
<meta property="og:image" content="https://내도메인.com/images/share.jpg">
<meta property="og:url" content="https://내도메인.com/">
```

넣을 때 자주 틀리는 부분은 세 가지입니다.

- **이미지 주소는 `https://`로 시작하는 전체 주소로** 적으세요. `/images/share.jpg`처럼 앞부분을 생략하면 외부 서비스가 사진을 못 찾는 경우가 있습니다.
- **og:url은 실제로 쓰는 내 도메인**과 같아야 합니다. 임시 주소가 남아 있으면 미리보기가 그쪽 정보를 따라갈 수 있어요. 도메인 연결은 [랜딩페이지를 무료로 올리고 내 도메인 연결하기](/posts/cloudflare-pages-domain/)를 참고하세요.
- **같은 태그를 두 번 넣지 마세요.** 빌더 설정과 직접 넣은 코드가 겹치면 어느 쪽이 뜰지 알 수 없습니다.

## 썸네일 이미지 고르는 법

미리보기 사진은 채팅방에서 작게, 그리고 서비스마다 다른 비율로 잘려서 보입니다. 그래서 정확한 크기보다 **잘려도 괜찮은 사진**을 고르는 게 중요해요.

- [ ] **가로로 긴 사진**을 쓰고, 중요한 내용은 **가운데**에 둡니다.
- [ ] 사진 위 글씨는 **짧게, 크게** 넣습니다. 작은 글씨는 휴대폰에서 읽히지 않아요.
- [ ] 로고만 덩그러니 있는 이미지보다 **매장·작업 결과가 보이는 사진**이 무엇을 하는 곳인지 더 빨리 전달합니다.
- [ ] 파일이 너무 무거우면 늦게 뜨거나 안 뜰 수 있습니다. 적당히 압축해 두세요.
- [ ] 다른 사람이 찍은 사진이나 인터넷에서 가져온 이미지는 쓰지 않습니다.

## 제목과 설명 문구는 이렇게

미리보기 카드는 대화 중에 스쳐 보는 곳입니다. **누가, 무엇을, 지금 할 수 있는지**가 한눈에 보여야 눌러 봐요.

| 아쉬운 예 | 고친 예 |
|---|---|
| Home | ○○네일 - 연남동 젤네일 예약 |
| 메인 페이지입니다 | 평일 저녁 9시까지, 카톡으로 바로 예약하세요 |
| Untitled | ○○인테리어 - 욕실 부분 시공 무료 견적 |

손님이 보는 곳이니 페이지 첫 화면 문구와 말투를 맞추면 좋습니다. 링크를 누른 뒤 바로 상담으로 이어지게 하려면 [카카오톡 상담 버튼 다는 법](/posts/kakao-channel-button/)도 함께 확인해 보세요.

## 바꿨는데 예전 미리보기가 계속 나올 때

카카오톡 같은 서비스는 한 번 읽어 간 미리보기 정보를 **한동안 저장(캐시)**해 두고 다시 씁니다. 그래서 태그를 고쳐도 바로 바뀌지 않는 경우가 많아요. 고장이 아니니 당황하지 마세요.

카카오디벨로퍼스에는 URL을 넣으면 카카오톡이 읽어 가는 OG 정보와 미리보기를 확인할 수 있는 도구가 있습니다. 문서 기준 메뉴 위치는 **[도구] > [카카오톡 URL 메타정보 관리]**이고, 여기서 주소를 조회하고 저장된 정보를 초기화할 수 있습니다. 카카오 계정 로그인이 필요합니다. ([카카오디벨로퍼스 – 도구 사용 가이드](https://developers.kakao.com/docs/latest/ko/tool/common))

그래도 안 바뀐다면 아래를 순서대로 확인하세요.

1. **페이지 소스에 새 태그가 실제로 들어갔나요?** 브라우저에서 "페이지 소스 보기"로 확인합니다. 저장만 하고 배포(게시)를 안 한 경우가 의외로 많아요.
2. **사진만 안 바뀌나요?** 이미지는 따로 저장되는 경우가 있습니다. 가장 확실한 방법은 **이미지 파일 이름을 바꿔서**(예: `share.jpg` → `share-2.jpg`) 다시 올리고 og:image 주소도 고치는 것입니다.
3. **주소 형태가 같나요?** `https://`가 있는 주소와 없는 주소, 끝에 `/`가 붙은 주소는 서로 다른 주소로 취급될 수 있습니다. 손님에게 보낼 주소 형태를 하나로 정해 두세요.
4. **휴대폰 앱에 남아 있는 건 아닌가요?** 도구에서는 바뀌었는데 내 폰에서만 예전 모습이라면, 다른 사람 폰이나 다른 채팅방에서 확인해 보세요.

## 정리

1. 카카오톡 미리보기는 페이지의 **OG 태그**(제목, 설명, 이미지, 주소)로 정해집니다.
2. 이미지는 **https 전체 주소**로, og:url은 **실제 내 도메인**으로 넣고, 태그가 중복되지 않게 합니다.
3. 썸네일은 **가로형, 중요한 내용은 가운데, 짧고 큰 글씨**가 기본입니다.
4. 고쳤는데 그대로라면 **배포 여부 → 카카오 도구로 조회·초기화 → 이미지 파일명 변경** 순서로 확인합니다.

지금 내 홈페이지 주소를 나에게 카톡으로 한 번 보내 보세요. 손님이 보는 첫인상이 거기 있습니다.
