홈페이지를 열고 며칠 뒤, 가게 이름으로 검색해 봤는데 아무것도 안 나오면 덜컥 걱정이 됩니다. "뭔가 잘못 만든 걸까?" 싶지만, 대부분은 **검색엔진이 아직 내 사이트를 모르는 상태**일 뿐이에요.

검색엔진은 인터넷의 페이지를 스스로 찾아다니지만, 막 만든 작은 사이트는 발견되기까지 시간이 걸립니다. 그래서 네이버와 구글은 사이트 주인이 직접 "제 사이트가 여기 있어요" 하고 알릴 수 있는 도구를 운영합니다. 네이버는 **서치어드바이저**, 구글은 **서치 콘솔**입니다.

이 글은 **등록 전에 페이지에서 확인할 것**, **등록하는 흐름**, **등록 뒤 점검할 것** 순서로 정리했습니다.

> 두 도구의 화면과 메뉴 이름은 자주 바뀝니다. 이 글은 전체 흐름을 설명하고, 실제 버튼 위치는 각 도구 안의 도움말 안내를 따라가시길 권합니다.

## 등록 전에 페이지에서 먼저 확인할 것

등록부터 하고 싶은 마음은 알지만, 페이지 자체에 문제가 있으면 등록해도 소용이 없습니다. 아래 다섯 가지를 먼저 보세요.

- [ ] **내 도메인으로 열리나요?** 임시 주소 말고 실제로 쓸 주소에서 등록해야 합니다. 도메인 연결이 아직이라면 [랜딩페이지를 무료로 올리고 내 도메인 연결하기](/posts/cloudflare-pages-domain/)부터 마무리하세요.
- [ ] **https로 열리나요?** 주소창에 자물쇠가 보이는지 확인합니다. 등록할 때도 실제로 쓰는 주소 형태 그대로 입력해야 헷갈리지 않습니다.
- [ ] **페이지 제목(title)이 제대로 들어가 있나요?** 브라우저 탭에 "Untitled"나 템플릿 이름이 보인다면 고쳐야 합니다.
- [ ] **페이지 설명(description)이 있나요?** 검색 결과에서 제목 아래 보이는 문장의 후보가 됩니다.
- [ ] **검색 차단 설정이 남아 있지 않나요?** 제작 중에 켜 둔 "검색엔진 노출 안 함" 설정이나 `noindex` 태그가 그대로 남아 있는 경우가 생각보다 흔합니다.

제목과 설명은 페이지의 `<head>` 안에 이렇게 들어갑니다.

```html
<title>강남 1:1 필라테스 ○○스튜디오 | 체험 수업 신청</title>
<meta name="description" content="강남역 5분, 1:1 맞춤 필라테스. 첫 체험 수업 신청을 받고 있습니다.">
```

제목에는 **가게 이름, 지역, 하는 일**이 들어가면 좋습니다. 손님이 실제로 검색할 말이 무엇인지 떠올려 보고, 억지로 단어를 나열하기보다 한 문장처럼 자연스럽게 쓰세요. 문구 자체를 다듬는 법은 [랜딩페이지 구성 순서 7단계](/posts/landing-page-structure/)의 첫 화면 부분을 참고하시면 됩니다.

## 사이트맵과 robots.txt, 이름만 알아 두세요

등록하다 보면 두 가지 낯선 단어가 나옵니다.

| 이름 | 쉽게 말하면 | 작은 가게 사이트에서는 |
|---|---|---|
| 사이트맵(sitemap.xml) | "제 사이트에는 이런 페이지들이 있어요" 하는 목록 | 페이지가 몇 개 안 되면 없어도 큰일은 아니지만, 있으면 제출해 두세요 |
| robots.txt | "이 페이지는 가져가도 되고, 저건 안 돼요" 하는 안내문 | 실수로 사이트 전체를 막아 두지 않았는지만 확인하세요 |

홈페이지 빌더를 쓰신다면 사이트맵이 자동으로 만들어지는 경우가 많으니, 사용 중인 빌더의 도움말에서 "사이트맵"을 검색해 주소를 확인하세요. 직접 만든 사이트라면 제작자에게 사이트맵 주소를 받아 두면 됩니다.

## 등록하는 흐름: 두 도구 모두 비슷합니다

네이버 서치어드바이저와 구글 서치 콘솔은 화면은 달라도 순서는 거의 같습니다.

1. **로그인하고 사이트 주소를 입력합니다.** 가게 계정으로 쓸 네이버·구글 계정을 정해서 로그인하세요. 개인 계정과 섞이면 나중에 관리하기 번거롭습니다.
2. **내 사이트가 맞는지 확인(소유 확인)합니다.** 도구가 알려 주는 코드 한 줄을 페이지 `<head>`에 넣거나, 확인용 파일을 사이트에 올리는 방식이 대표적입니다. 빌더를 쓴다면 보통 "외부 코드 삽입"이나 "검색엔진 설정" 같은 메뉴에 붙여 넣습니다.
3. **사이트맵 주소를 제출합니다.** 있다면 넣어 두세요.
4. **중요한 페이지는 직접 수집을 요청합니다.** 첫 페이지와 광고·QR이 연결되는 랜딩페이지 주소가 우선입니다.

소유 확인 코드는 **확인이 끝난 뒤에도 지우지 마세요.** 나중에 사이트를 고치다 코드가 사라지면 다시 확인해야 할 수 있습니다. 제작을 맡길 때는 이 코드를 남겨 달라고 미리 말해 두면 좋습니다.

## 등록 뒤에 점검할 것

등록했다고 바로 검색에 나오지는 않습니다. 언제 반영될지는 검색엔진이 정하고, 등록이 노출을 보장하지도 않아요. 조급해하지 말고 아래만 챙기세요.

- [ ] 일주일쯤 뒤 도구에 다시 들어가 **오류나 경고 알림**이 있는지 봅니다.
- [ ] 수집이 안 된 페이지가 있다면, 그 페이지가 위에서 본 **검색 차단 설정**에 걸려 있지 않은지 다시 확인합니다.
- [ ] 페이지 주소를 바꿨다면 새 주소로 **사이트맵을 다시 제출**합니다.
- [ ] 가게 이름, 주소, 전화번호가 홈페이지와 지도·플레이스 정보에서 **똑같이** 적혀 있는지 맞춥니다.

그리고 검색 등록은 "찾아오는 길"을 하나 더 내는 일이지, 손님을 끌어오는 일은 아닙니다. 가게 이름 검색에는 비교적 잘 잡히지만 "강남 필라테스"처럼 넓은 검색어에서 위에 뜨는 건 별개의 문제예요. 처음에는 **가게 이름으로 검색했을 때 내 사이트가 나오는 것**을 목표로 잡으세요. 들어온 손님이 바로 떠나지 않게 하려면 [모바일 속도 점검](/posts/mobile-page-speed-check/)도 함께 해 두면 좋습니다.

## 정리

1. 검색에 안 나오는 건 대부분 **검색엔진이 아직 모르는 것**입니다. 네이버는 서치어드바이저, 구글은 서치 콘솔로 직접 알립니다.
2. 등록 전에 **내 도메인, https, 제목·설명, 검색 차단 설정**을 먼저 확인합니다.
3. 등록은 **주소 입력 → 소유 확인 → 사이트맵 제출 → 중요한 페이지 수집 요청** 순서입니다.
4. 소유 확인 코드는 **지우지 말고**, 등록 뒤에는 오류 알림과 가게 정보 일치 여부를 가끔 점검합니다.

한 번 등록해 두면 그다음부터는 가끔 들여다보기만 하면 됩니다. 사이트를 연 주에 30분만 투자해 두세요.
