랜딩페이지를 HTML 파일로 받았다면, 서버를 빌리지 않고도 무료로 인터넷에 올릴 수 있습니다. 이 글은 **Cloudflare Pages**를 기준으로 설명합니다.

Cloudflare Pages를 고른 이유는 하나입니다. 공식 문서에 **"무료·유료 플랜 모두 정적 파일 요청은 무료이고 무제한"**이라고 적혀 있어서, 광고로 방문자가 몰려도 요금이 나오거나 사이트가 멈출 걱정이 적습니다. ([Cloudflare Pages 요금 문서](https://developers.cloudflare.com/pages/functions/pricing/))

> 메뉴 이름과 한도는 2026년 9월 30일 Cloudflare 공식 문서 기준입니다. 화면은 업데이트에 따라 조금 다를 수 있으니, **입력할 값은 내 Cloudflare 화면에 나온 값을 그대로 복사**하세요.

## 시작 전에 확인할 것

- [ ] 페이지 파일이 **폴더 하나**에 모여 있고, 그 안에 `index.html`이 바로 보이나요?
- [ ] 파일이 너무 크지 않나요? 끌어다 놓기 방식은 **파일 1,000개, 파일 하나당 25MiB**까지 올릴 수 있습니다. ([Direct Upload 문서](https://developers.cloudflare.com/pages/get-started/direct-upload/)) 랜딩페이지 한 장이면 넉넉합니다.
- [ ] 도메인을 연결할 거라면, 도메인을 산 곳(가비아 등)에 **내 계정으로 로그인**할 수 있나요?

## 1단계: Cloudflare 가입

1. [Cloudflare 가입 페이지](https://dash.cloudflare.com/sign-up)에서 이메일로 가입하고, 받은 메일에서 인증을 누릅니다.
2. 사이트를 올리는 데는 결제 수단이 필요 없습니다.

계정은 **사업자 본인 명의**로 만드세요. 제작자 계정에 올려두면 나중에 업체를 바꾸거나 연락이 끊겼을 때 사이트를 옮기기 어렵습니다.

## 2단계: 폴더 끌어다 놓아 올리기

1. 대시보드 왼쪽 메뉴에서 **Workers & Pages**를 누릅니다.
2. **Create application → Get started → Drag and drop your files**를 차례로 누릅니다.
3. **프로젝트 이름**을 영문으로 정합니다. 이 이름이 기본 주소가 됩니다. 예: `onyul-pilates` → `onyul-pilates.pages.dev`
4. 점선 상자에 페이지 **폴더째** 끌어다 놓고 **Deploy site**를 누릅니다.
5. 잠시 뒤 생긴 `https://프로젝트이름.pages.dev` 주소를 눌러 페이지가 보이면 성공입니다.

**수정본을 올릴 때**는 같은 프로젝트에서 새 배포를 만들고 고친 폴더를 다시 끌어다 놓으면 됩니다. 주소는 그대로 유지돼요.

## 3단계: 어떤 주소로 연결할지 정하기

내 도메인을 연결하는 방법은 두 가지이고, 난이도가 꽤 다릅니다.

| 방식 | 예시 | 해야 할 일 | 난이도 |
|---|---|---|---|
| **서브도메인** | `www.내가게.com`, `event.내가게.com` | 도메인 산 곳에 CNAME 레코드 1개 추가 | 쉬움 |
| **루트 도메인** | `내가게.com` | 도메인을 Cloudflare에 사이트로 추가하고 **네임서버를 Cloudflare로 변경** | 보통 |

Cloudflare 문서에 따르면 루트 도메인에 연결하려면 그 도메인을 **Cloudflare에 사이트(zone)로 추가**해야 하고, 서브도메인은 그럴 필요 없이 기존 DNS에 CNAME만 넣으면 됩니다. ([커스텀 도메인 문서](https://developers.cloudflare.com/pages/configuration/custom-domains/))

처음이라면 **서브도메인(`www`)으로 시작**하는 걸 추천합니다. 메일 같은 기존 설정을 건드리지 않아도 되기 때문입니다.

## 4단계: 서브도메인 연결하기

1. **Workers & Pages → 내 프로젝트 → Custom domains** 탭으로 갑니다.
2. 도메인 추가 버튼(Set up a custom domain)을 누르고 `www.내가게.com`을 입력합니다.
3. Cloudflare가 넣어야 할 **CNAME 값**을 보여줍니다. 보통 `프로젝트이름.pages.dev` 모양입니다. 화면에 나온 값을 복사해 두세요.
4. 도메인을 산 곳의 **DNS 관리(레코드 관리)** 화면에서 레코드를 추가합니다.

| 항목 | 입력할 값 |
|---|---|
| 타입 | `CNAME` |
| 호스트(이름) | `www` |
| 값 | 3번에서 복사한 값 (예: `onyul-pilates.pages.dev`) |

5. 저장한 뒤 Cloudflare 화면에서 상태가 바뀔 때까지 기다립니다. 보통 몇 분에서 몇 시간이 걸리고, 길면 하루 정도 걸릴 수 있습니다.

> ⚠️ 순서가 중요합니다. Cloudflare 문서에 따르면 **대시보드에서 도메인을 먼저 추가**해야 레코드가 제대로 동작합니다. 도메인 업체에 CNAME만 넣고 끝내면 연결되지 않습니다.

**자주 하는 실수**
- CNAME 값에 `https://`를 붙임 → 주소만 입력하세요.
- 호스트 칸에 `www.내가게.com` 전체를 입력 → 업체 화면에 도메인이 이미 붙어 있다면 `www`만 입력합니다.
- 메일용 **MX 레코드**나 인증용 **TXT 레코드**를 지움 → 이 레코드들은 건드리지 마세요. 메일이 끊길 수 있습니다.

## 루트 도메인(`내가게.com`)도 쓰고 싶다면

방법은 두 가지입니다.

1. **도메인을 Cloudflare로 옮기기**: Cloudflare에 사이트를 추가하고, 도메인 업체에서 네임서버를 Cloudflare가 알려주는 값으로 바꿉니다. 이때 기존 DNS 설정(메일 등)이 Cloudflare로 잘 옮겨졌는지 반드시 확인하세요.
2. **포워딩으로 넘기기**: 도메인 업체가 **URL 포워딩** 기능을 제공한다면 `내가게.com`으로 들어온 사람을 `www.내가게.com`으로 보내도록 설정할 수 있습니다. 제공 여부와 메뉴는 업체마다 다릅니다.

처음 연결할 때는 2번이 간단하고, DNS 관리를 한곳에서 하고 싶을 때 1번을 고려하세요.

## 연결 후 체크리스트

- [ ] `www.내가게.com`이 열리나요?
- [ ] 주소창에 자물쇠(https)가 보이나요?
- [ ] 휴대폰 데이터(와이파이 끄고)로도 열리나요?
- [ ] 상담 폼이 새 주소에서도 잘 접수되나요? ([구글 시트 폼 설정](/posts/form-to-google-sheets/) 참고)
- [ ] 광고, SNS 프로필, 명함에 적힌 주소를 새 주소로 바꿨나요?

## 정리

- Cloudflare Pages는 정적 페이지 요청이 무료·무제한이라, 광고용 랜딩페이지를 올리기에 부담이 적습니다.
- **Workers & Pages → Create application → Drag and drop your files**로 폴더째 올리면 `프로젝트이름.pages.dev` 주소가 생깁니다.
- 내 도메인은 **서브도메인(`www`)부터** 연결하세요. 대시보드에서 먼저 추가한 뒤, 도메인 업체에 CNAME 1개만 넣으면 됩니다.
- 루트 도메인은 네임서버 변경이 필요하니, 기존 메일 설정을 확인한 뒤 진행하세요.
