랜딩페이지 제작을 맡기고 "완성됐습니다" 연락을 받으면 반가운 마음에 바로 잔금을 보내기 쉽습니다. 그런데 문제는 대개 **광고를 켜고 손님이 들어오기 시작한 뒤**에 보입니다. 폼이 안 들어오거나, 휴대폰에서 버튼이 가려지거나, 문구 하나 고치려는데 연락이 안 되는 식이죠.

이 글은 납품을 받는 날 30분만 들여서 확인할 것들을 정리한 체크리스트입니다. 제작 비용과 의뢰 전 준비는 [랜딩페이지 제작 비용, 얼마가 적당할까?](/posts/landing-page-cost/)에서 다뤘으니, 여기서는 **받을 때**만 이야기합니다.

## 검수는 언제, 어떻게 하나요?

가장 좋은 때는 **잔금을 보내기 전**입니다. 결제가 끝난 뒤에는 같은 요청도 "추가 수정"으로 처리될 수 있어요.

검수할 때는 이렇게 준비하세요.

- **내 휴대폰**과 **가족이나 직원 휴대폰** 한 대씩 (기종이 다르면 더 좋습니다)
- 컴퓨터 한 대
- 처음 의뢰할 때 보낸 요청 내용 (문구, 사진, 참고 사이트)

고칠 점은 말로 전하지 말고 **화면 캡처 + 한 줄 설명**으로 모아서 한 번에 보내세요. 여러 번 나눠 보내면 서로 헷갈리고 수정 횟수만 늘어납니다.

## 1. 휴대폰 화면부터 봅니다

동네 가게 손님은 대부분 휴대폰으로 들어옵니다. 컴퓨터 화면이 예뻐도 휴대폰에서 불편하면 소용이 없어요.

- [ ] 첫 화면에 **무슨 가게인지**와 **신청 버튼**이 보이나요?
- [ ] 글자가 너무 작아서 확대해야 읽히는 곳은 없나요?
- [ ] 사진이 잘리거나 옆으로 밀려서 가로 스크롤이 생기지 않나요?
- [ ] 화면 아래에 고정된 버튼이 다른 내용을 가리지 않나요?
- [ ] 와이파이를 끄고 휴대폰 데이터로 열었을 때도 금방 뜨나요?

속도가 느리다고 느껴지면 [내 홈페이지 모바일 속도 점검하는 법](/posts/mobile-page-speed-check/)을 참고해 제작자에게 구체적으로 요청하세요.

## 2. 버튼과 폼은 직접 눌러 봅니다

눈으로 보는 것보다 **직접 신청해 보는 것**이 훨씬 중요합니다. 실제 손님처럼 처음부터 끝까지 해 보세요.

| 확인할 것 | 어떻게 확인하나요 |
|---|---|
| 상담 신청 폼 | 테스트로 신청한 뒤, 내가 받기로 한 곳(메일, 시트 등)에 들어왔는지 확인 |
| 전화 버튼 | 휴대폰에서 눌렀을 때 내 번호로 전화 화면이 뜨는지 |
| 카카오톡 버튼 | 내 채널로 연결되는지, 다른 가게 채널이 아닌지 |
| 지도·주소 | 지도 앱에서 실제 매장 위치가 맞게 뜨는지 |
| 완료 화면 | 신청 후 "접수되었습니다" 같은 안내가 나오는지 |

특히 폼은 **신청 알림을 누가 받는지**를 꼭 물어보세요. 제작자 메일로 설정된 채로 넘겨받으면 손님 신청이 엉뚱한 곳으로 갑니다. 테스트 신청은 확인 후 지워 달라고 하거나 직접 정리하세요.

## 3. 문구와 정보를 하나씩 대조합니다

처음 보낸 요청 내용을 옆에 두고 비교하세요.

- [ ] 가게 이름, 전화번호, 주소, 영업시간에 오타가 없나요?
- [ ] 가격이나 이벤트 내용이 지금 기준과 같나요?
- [ ] 예시용 글("여기에 소개 문구를 입력하세요")이나 샘플 사진이 남아 있지 않나요?
- [ ] 개인정보 동의 문구가 들어가 있나요?
- [ ] 브라우저 탭에 뜨는 페이지 제목이 우리 가게 이름인가요?

전화번호 한 자리만 틀려도 손님은 연락할 방법이 없습니다. 숫자는 꼭 두 번 확인하세요.

## 4. 계정과 자료를 받아 둡니다

검수에서 가장 많이 놓치는 부분입니다. 페이지가 잘 보여도 **내 손에 쥔 것이 없으면** 나중에 업체를 바꾸거나 연락이 끊겼을 때 처음부터 다시 만들어야 할 수 있어요.

| 받아 둘 것 | 왜 필요한가요 |
|---|---|
| 도메인 계정 (내 명의) | 주소를 계속 쓰고, 연장 시기를 직접 챙기기 위해 |
| 호스팅·빌더 계정 (내 명의) | 다른 제작자에게 맡기거나 직접 고칠 때 |
| 폼·시트·분석 도구 접근 권한 | 신청 내역과 방문 기록을 내가 볼 수 있게 |
| 원본 파일 (코드 또는 디자인 파일) | 계약에 포함된 경우, 나중에 수정할 때 |
| 사진·로고 원본 | 다른 곳(스마트플레이스, 인쇄물)에도 쓰기 위해 |

계정은 **비밀번호를 내가 새로 바꿀 수 있는 상태**인지까지 확인하세요. 제작자 메일로 가입된 계정이면 로그인 메일 주소를 내 것으로 바꿔 달라고 요청하면 됩니다. 원본 파일을 넘겨주는지는 업체마다 다르니, 가능하면 계약 전에 물어보는 것이 좋습니다.

## 5. 납품 후 수정 범위를 글로 남깁니다

사이트는 만들고 끝이 아니라 계속 고쳐 쓰게 됩니다. 아래 세 가지를 메시지나 메일로 **글로 남겨** 두세요.

1. **무료로 고쳐 주는 기간과 횟수**: 예) "납품 후 2주, 문구 수정 3회까지"
2. **그 이후 수정은 어떻게 하나요**: 건당 비용인지, 다시 견적을 받는지
3. **연락 방법과 답변 시간**: 급한 오류(폼이 안 될 때)는 어디로 연락하면 되는지

말로만 정해 두면 나중에 서로 기억이 다를 수 있습니다. 기준을 서로 같이 알고 있으면 오히려 관계도 편해져요.

## 정리

- 검수는 **잔금 전에**, 휴대폰 두 대와 처음 요청 내용을 옆에 두고 합니다.
- 화면만 보지 말고 **폼·전화·카카오톡 버튼을 직접 눌러** 실제로 연결되는지 확인하세요.
- 도메인·호스팅·폼 계정은 **내 명의, 내 비밀번호**로 받아 두세요.
- 무료 수정 기간과 이후 비용은 **글로 남겨** 두면 서로 편합니다.
- 고칠 점은 캡처와 한 줄 설명으로 모아 **한 번에** 전달하세요.
