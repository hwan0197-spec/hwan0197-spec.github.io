랜딩페이지를 맡기려고 알아보면 10만 원짜리도 있고 100만 원이 넘는 곳도 있습니다. 가격 차이가 왜 이렇게 나는지, 내 상황에는 어느 정도가 맞는지 판단할 기준을 정리했습니다.

## 가격대별로 받을 수 있는 것

프리랜서 마켓 크몽이 공개한 거래 데이터(2025년 9월 기준)를 보면 랜딩페이지 제작 비용은 대략 세 구간으로 나뉩니다.

| 구간 | 가격 | 주로 포함되는 것 |
|---|---|---|
| 저가형 | 6만~10만 원 | 기존 템플릿 수정, 간단한 이벤트 페이지 |
| 일반형 | 30만~80만 원 | 맞춤 디자인, 반응형, 섹션별 구성 |
| 고급형 | 100만 원 이상 | 쇼핑몰·결제 연동, 애니메이션, 분석 코드 |

> 출처: [크몽 랜딩페이지 제작 비용 안내](https://kmong.com/prices/%EB%9E%9C%EB%94%A9%ED%8E%98%EC%9D%B4%EC%A7%80-%EC%A0%9C%EC%9E%91). 실제 견적은 요구사항에 따라 달라집니다.

동네 가게나 1인 사업자가 **상담 신청을 받는 용도**라면 대부분 일반형 구간 안에서 해결됩니다. 결제 기능이 필요한 게 아니라면 고급형까지 갈 이유는 많지 않아요.

## 가격을 올리는 다섯 가지

같은 "랜딩페이지"라도 아래 항목에서 견적이 크게 갈립니다.

1. **섹션 수**: 보통 4~5개를 넘으면 추가 비용이 붙습니다. 섹션은 "공감 → 해결책 → 가격 → 후기 → 신청"처럼 화면을 나누는 덩어리를 말해요.
2. **디자인 맞춤 정도**: 템플릿에 글만 바꾸는 것과 브랜드에 맞게 새로 디자인하는 것은 작업량이 다릅니다.
3. **모바일 대응(반응형)**: 요즘은 기본으로 포함하는 곳이 많지만, 별도 옵션으로 받는 곳도 있으니 꼭 확인하세요.
4. **연동 기능**: 상담 폼, 카카오톡 채널 버튼, 광고 추적 코드, 결제 같은 기능이 붙을수록 올라갑니다.
5. **자료 준비 상태**: 문구와 사진이 정리되어 있으면 싸지고, "알아서 써주세요"면 기획·카피 비용이 더해집니다.

## 견적서에 잘 안 적히는 비용

제작비만 보고 결정하면 나중에 매달 나가는 돈에 놀랄 수 있습니다. 계약 전에 아래를 꼭 물어보세요.

| 항목 | 대략적인 비용 | 확인할 것 |
|---|---|---|
| 도메인 (예: `내가게.com`) | 1년에 약 1만~2.5만 원 | 첫해 할인가와 **연장 가격**이 다른 경우가 많아요 |
| 호스팅 (사이트를 올려두는 곳) | 무료~월 몇만 원 | 정적 페이지는 무료 호스팅으로 충분한 경우가 많아요 |
| 홈페이지 빌더 요금 | 월 요금제 | 빌더로 만들면 **계속 구독해야** 페이지가 유지돼요 |
| 수정 비용 | 건당 청구 | 납품 후 문구 하나 바꾸는 데도 돈이 드는지 확인하세요 |

> 도메인 가격 예시: 가비아 기준 `.com` 첫해 19,800원, 정상가 26,400원 (2026년 7월 기준). 등록 업체와 이벤트에 따라 달라집니다.

특히 **누구 명의로 등록되는지**가 중요합니다. 도메인과 호스팅 계정이 제작자 명의로 되어 있으면, 나중에 업체를 바꾸거나 연락이 끊겼을 때 내 사이트를 옮기기 어렵습니다. 처음부터 내 계정으로 만들어 달라고 요청하세요.

## 의뢰 전에 준비하면 비용이 줄어드는 것

제작자에게 아래 다섯 가지를 정리해서 보내면 견적이 정확해지고, 수정 횟수도 줄어듭니다.

1. **이 페이지로 받고 싶은 행동 하나**: 상담 신청, 전화, 카카오톡 문의, 예약 중 무엇이 가장 중요한가요?
2. **꼭 들어가야 할 내용**: 서비스 소개, 가격, 위치, 영업시간, 자주 묻는 질문
3. **사진과 로고**: 없으면 무료 이미지로 대체할 수 있는지 물어보세요.
4. **참고 사이트 2~3개**: "이런 느낌이 좋다"를 말로 설명하는 것보다 훨씬 정확합니다.
5. **원하는 완료 날짜**: 급하면 추가 비용이 붙는 경우가 많으니 여유 있게 잡으세요.

## 이런 경우엔 직접 만들어도 됩니다

- 이벤트 기간에만 잠깐 쓰는 페이지
- 문구와 이미지만 있으면 되는 아주 단순한 소개 페이지
- 빌더 사용에 익숙하고, 월 요금이 부담되지 않는 경우

반대로 **광고비를 쓰면서 보내는 페이지**라면, 제작비를 아끼다가 광고비가 새는 경우가 더 많습니다. 페이지에서 신청이 잘 안 나오면 광고비 전체의 효율이 떨어지기 때문이에요.

## 정리

- 상담 신청용 랜딩페이지는 **30만~80만 원 구간**이 일반적이고, 요구사항이 단순하면 그 아래도 가능합니다.
- 제작비보다 **매달 나가는 유지비**와 **계정 명의**를 먼저 확인하세요.
- 받고 싶은 행동 하나, 필요한 내용, 참고 사이트를 미리 정리하면 견적과 기간이 모두 줄어듭니다.
